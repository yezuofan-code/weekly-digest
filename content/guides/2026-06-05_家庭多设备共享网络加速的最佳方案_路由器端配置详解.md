# 一次设置，全家自动加速：路由器端全屋网络加速配置指南

你有没有这种经历：家里五六台设备——手机、电脑、iPad、电视、游戏机——每台都要单独装软件、手动更新订阅、时不时还要排查哪个接入点挂了？我踩过这个坑整整两年，直到去年花了一个周末折腾路由器端配置，现在全家人看电视、刷Ins、查资料，**完全不用管底层是怎么连的**。今天就手把手教你搞定这个“一次性部署，全家省心”的方案。

## 为什么我推荐在路由器上折腾，而不是每台设备单独搞？

先说说我在用过的方案对比。2023年我试过三种思路：

| 方案类型 | 维护成本 | 设备兼容性 | 延迟表现 | 适合场景 |
|---------|---------|-----------|---------|---------|
| 每台设备单独装客户端 | 极高（每次更新要搞5-6台） | 电视、游戏机经常不支持 | 低（独立运行） | 只有1-2台设备 |
| 路由器端全局代理 | 极低（一次配置全家用） | **所有设备自动接管** | 中等（依赖路由器性能） | 家庭多设备共享 |
| 软路由+分流规则 | 中等（需要设置分流） | 所有设备 | 优（可精细化） | 追求极致体验的玩家 |

**我的结论**：如果你家有3台以上设备需要访问国际网络，或者有电视、游戏机这类不方便装客户端的设备，**路由器端配置绝对是最省心的选择**。虽然初期需要花1-2小时设置，但之后半年都不用碰它。

## 准备工作：选对网络加速服务和路由器固件

### 第一步：挑一个支持订阅链接的服务商

路由器端的配置核心是 **订阅链接**——你可以把它理解成一个“菜单”，路由器自动从这个链接下载所有接入点的配置信息，然后根据你设定的规则自动切换。

我目前在用的是 **[自由猫](https://api.huanghaiwan.com/go/自由猫)**（用了8个月），推荐理由是它的配置对路由器端特别友好，订阅链接可以直接导入OpenWrt和梅林，而且 **IEPL专线在晚高峰表现稳如老狗**。不过我也得说句实话：它起步价不算便宜（月付29元起），如果你设备不多，先别冲动，**一定要先买个最小流量包测试**。

<details>
<summary>⚠️ 省钱建议：别急着买年付</summary>

大多数服务商都提供月付选项。我的建议是：
1. 先买个最便宜的月付套餐（15-30元档）
2. 在路由器上用一周，观察晚高峰的表现
3. 确定满意了再考虑年付
不要在没测试网络环境的情况下直接买年付——我同事就是血泪教训，买了一年结果他家移动宽带连不上。
</details>

另外，**[闪狐云](https://api.huanghaiwan.com/go/闪狐云)**也是不错的选择，它的**BGP中转+IPLC专线出口**在同价位里算性价比很高的，20元/月就能用200G流量，而且新上线有优惠。

### 第二步：确认你的路由器固件

- **如果你的路由是刷了OpenWrt/梅林/Padavan的** → 直接跳到下一节
- **如果你的路由是原厂固件（如小米、华硕原厂、TP-Link）** → 需要先刷机或买软路由
- **极度怕折腾** → 买一个刷好OpenWrt的R2S/R4S软路由（200-500元），直接插上配置

> 💡 我个人推荐 **OpenWrt**，因为它的“PassWall”或“ShadowSocksR Plus+”插件，是配置这类功能最直观的入口。梅林固件的“访问国际网络”插件也可以，但更新频率没OpenWrt快。

## 核心配置步骤：以OpenWrt + PassWall为例

下面我用 **X86软路由刷的OpenWrt 23.05** 演示，其他固件步骤类似但界面不同。

### 步骤1：安装PassWall插件

如果你的OpenWrt里没有这个插件，可以通过软件包管理安装：
```
opkg update
opkg install luci-app-passwall
```
或者在固件后台找到「系统→软件包」，搜索`passwall`安装。这步大概需要5分钟。

### 步骤2：获取订阅链接并导入

这一步是**最关键**的，出错率也最高。

1. 登录你的服务商网站（比如自由猫或闪狐云），找到「订阅链接」页面
2. 复制 **Clash订阅链接**（不是SSR/SS链接，有些服务商会分开）
3. 回到OpenWrt后台 → 服务 → PassWall → 接入点订阅
4. 点击「添加」，填入：
   - **订阅URL**：你刚复制的链接
   - **订阅类型**：选择 `Clash`
   - **自动更新**：建议开「每天」
5. 点击「保存&应用」

> ⚠️ **常见错误**：如果导入后接入点列表为空，大概率是订阅链接格式不对。试试换「SS/SSR」或「V2ray」类型，或者检查链接末尾有没有多余空格。

### 步骤3：设置全局规则（最易踩坑的地方）

PassWall默认是**全局代理**，也就是所有流量都走海外接入点。这会让**国内网站变慢**，因为绕路了。我建议改成**智能分流**：

1. 在PassWall → 基础设置 → 主开关 → 开启
2. **模式选择**：`GFW列表`（即只有访问海外站点才走代理，国内直连）
3. **DNS设置**：上游DNS填 `8.8.8.8` 和 `1.1.1.1`，国内DNS填 `114.114.114.114`
4. **绕过中国大陆IP**：勾选上（这个会自动识别国内IP直连）

这样设置后，你看B站、刷淘宝、用钉钉都是直连，只有访问外网时走接入点。我实测延迟几乎无感知。

### 步骤4：选择接入点并测试

1. 在PassWall → 接入点列表 → 选择一个延迟低的接入点（一般不超过200ms）
2. 点击「测试」观察延迟
3. 如果延迟正常，回到「基础设置」接入点选择你刚刚测试的接入点
4. 找一个你之前打不开的海外网站（比如ChatGPT或Instagram），确认能正常访问

**我踩过的坑**：第一次配置时忘了在PassWall里**关闭「IPv6」**。国内很多网络运营商对IPv6支持不好，开启了会导致部分海外网站加载慢。如果你发现连上了但卡顿，进「高级设置」关掉IPv6试试。

## 进阶玩法：多接入点自动切换+流媒体解锁

如果你和我一样懒，每天不想手动切接入点，可以设置**自动切换规则**：

在PassWall → 自动切换 → 添加策略：
- **故障转移**：主接入点ping超时自动换备用接入点（建议所有接入点都加上）
- **延迟优先**：每5分钟自动选当前延迟最低的接入点（适合追求速度的日常使用）

**对于流媒体解锁**：如果你家电视要看Netflix或Disney+，建议把**香港接入点**作为主力。我测试下来，香港接入点对Netflix和B站海外站的支持最稳定，延迟也低。自由猫的香港接入点我用了半年，1080p无缓冲。

> 🔧 **冷知识**：如果设置了自动切换但某个设备（比如Chromecast）还是卡，可以单独给这个设备写一个MAC地址过滤规则。在PassWall → 访问控制 → MAC过滤里，把该设备流量走特定接入点。

## 总结：花一天配置，换全家半年省心

最后总结一下我的核心观点：

1. **路由器端配置是家庭多设备共享的最优解**，尤其适合有电视、游戏机或老人/小孩用的设备
2. **如果你怕麻烦，选对服务商和固件能省一半时间**——优先选支持Clash订阅链接、提供IEPL专线的服务商（如自由猫、闪狐云），它们的订阅导入出错率低
3. **配置完成后：** 你一定得测试晚高峰（晚上8-10点）的表现。如果发现卡顿，切到其他国家接入点试试，日本接入点通常晚上最稳
4. **不要被“全屋自动加速”这个词劝退**：你真正需要操作的步骤不超过10个，剩下都是等待
